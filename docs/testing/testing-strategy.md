# Testing Strategy

## Purpose

The repository includes a minimal but real testing foundation for Module 1.

## Coverage

- Unit tests for API health behavior
- Unit tests for shared type contracts
- E2E infrastructure for future browser-level validation

## Commands

- pnpm test
- pnpm test:e2e

## Rules

- Avoid placeholder test scripts.
- Add tests for meaningful behavior before shipping features.
- Keep test scope limited to the current engineering foundation.
