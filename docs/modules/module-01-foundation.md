# Module 01: Foundation

## Objective

Establish the engineering infrastructure required before business features are introduced.

## Included

- pnpm workspace and Turborepo setup
- web app foundation
- API foundation
- shared package structure
- Supabase folders
- documentation skeleton
- testing and Playwright setup
- CI pipeline

## Excluded

- customer, user, workspace, and messaging features
- AI and automation flows
- notifications, reminders, analytics, and billing
- business database tables
